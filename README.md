# mtrmuti-clone

เว็บไซต์สาขาวิชา (ต้นแบบจาก mtrmuti.com) พัฒนาด้วย **PHP + MySQL ล้วน** เพื่อให้รันได้บน shared hosting ของ CloudRambo (cPanel) โดยตรง พร้อมระบบหลังบ้าน (admin panel) สำหรับอัพเดตเนื้อหาแต่ละหน้าเอง โดยไม่ต้องแก้โค้ด

## โครงสร้างโปรเจค

```
/                       หน้าเว็บไซต์สาธารณะ (index.php, course.php, teachers.php, ...)
/includes/              header, footer, ฟังก์ชันช่วยเหลือ (functions.php)
/config/config.php      ตั้งค่าการเชื่อมต่อฐานข้อมูล
/assets/css/style.css   ธีมสีแดง-ขาว-ดำ + เลย์เอาต์การ์ด/สไลด์
/assets/uploads/        ไฟล์รูปภาพที่อัพโหลดผ่านระบบหลังบ้าน
/admin/                 ระบบหลังบ้านสำหรับอัพเดตข้อมูล
/db/schema.sql          โครงสร้างฐานข้อมูล + ข้อมูลตั้งต้น
```

หน้าเว็บไซต์ที่มีให้: หน้าหลัก, หลักสูตรปริญญาตรี, ประวัติหลักสูตร, รายวิชาที่เปิดสอน, อาจารย์, ห้องเรียน, นักศึกษาปัจจุบัน, ศิษย์เก่า, บริการนักศึกษา, Classroom Online, ติดต่อเรา — ครบตามโครงสร้างเมนูของ mtrmuti.com

## วิธีติดตั้งบน CloudRambo (cPanel)

1. **สร้างฐานข้อมูล MySQL**
   ใน cPanel ไปที่ *MySQL Databases* สร้างฐานข้อมูล + ผู้ใช้ + สิทธิ์ ALL PRIVILEGES แล้วจดชื่อ database/user/password ไว้

2. **นำเข้าโครงสร้างฐานข้อมูล**
   เปิด *phpMyAdmin* เลือกฐานข้อมูลที่สร้าง แล้ว Import ไฟล์ `db/schema.sql`
   (ถ้าเคย import `db/schema.sql` ไปแล้วก่อนหน้านี้ ให้ import ไฟล์ใน `db/migrations/` เพิ่มเติมตามลำดับเลขไฟล์ เพื่ออัพเดตโครงสร้างตารางที่เพิ่มใหม่ทีหลัง)

3. **อัพโหลดไฟล์เว็บไซต์**
   อัพโหลดทุกไฟล์ในโปรเจคนี้ไปที่ `public_html` (หรือโฟลเดอร์โดเมนของ mtrmuti.com) ผ่าน FTP หรือ File Manager

4. **ตั้งค่าการเชื่อมต่อฐานข้อมูล**
   แก้ไข `config/config.php` ใส่ค่า `DB_HOST` (ปกติ `localhost`), `DB_NAME`, `DB_USER`, `DB_PASS` ตามที่สร้างไว้ในขั้นตอนที่ 1

5. **สร้างบัญชีผู้ดูแลระบบ**
   เปิดเบราว์เซอร์ไปที่ `https://mtrmuti.com/admin/install.php` กรอกชื่อผู้ใช้/รหัสผ่านที่ต้องการ
   **สำคัญ: หลังสร้างบัญชีเสร็จ ให้ลบไฟล์ `admin/install.php` ออกจากเซิร์ฟเวอร์ทันที** เพื่อไม่ให้คนอื่นสร้างบัญชีแอดมินซ้ำได้

6. **ตรวจสอบสิทธิ์โฟลเดอร์**
   ให้แน่ใจว่า `assets/uploads/` เขียนไฟล์ได้ (permission 755 หรือ 775 ตามที่ hosting กำหนด) เพื่อให้อัพโหลดรูปผ่านหลังบ้านได้

7. **เพิ่มขนาดไฟล์อัพโหลดสูงสุดของ PHP**
   ค่าเริ่มต้นของ hosting ส่วนใหญ่ (`upload_max_filesize` มักอยู่ที่ 2MB, `post_max_size` ที่ 8MB) เล็กเกินไปสำหรับไฟล์เล่มหลักสูตร (PDF) หรือรูปภาพขนาดใหญ่ ให้เพิ่มค่าดังนี้ (แนะนำอย่างน้อย 32MB / 40MB ตามลำดับ):
   - **วิธีที่แนะนำ**: ใน cPanel ไปที่ *MultiPHP INI Editor* เลือกโดเมน mtrmuti.com แล้วปรับ `upload_max_filesize` และ `post_max_size`
   - **ถ้าไม่มีเมนูนั้น**: สร้างไฟล์ `.user.ini` ไว้ที่ root ของเว็บ (โฟลเดอร์เดียวกับ `index.php`) ใส่เนื้อหา:
     ```
     upload_max_filesize = 32M
     post_max_size = 40M
     ```
     แล้วรอสักครู่ให้ค่ามีผล (PHP จะอ่านไฟล์นี้ใหม่ทุก ๆ ไม่กี่นาที)

8. **เข้าสู่ระบบหลังบ้าน**
   ไปที่ `https://mtrmuti.com/admin/index.php` ใช้บัญชีที่สร้างในขั้นตอนที่ 5

## สิ่งที่แก้ไขได้ผ่านระบบหลังบ้าน

- เนื้อหาของทุกหน้า (ชื่อหัวข้อ, คำโปรย, เนื้อหาแบบ rich text) — เมนู "แดชบอร์ด" > แก้ไขเนื้อหา
- ทำเนียบอาจารย์ (รูป, ชื่อ, ตำแหน่ง, เบอร์โทร, อีเมล) และหน้าโปรไฟล์รายบุคคล: ประวัติ, วุฒิการศึกษา, วิชาที่สอน, ผลงานวิจัย, ผลงานสร้างสรรค์, ผลงานนวัตกรรม, ผลงานประกวด, ทรัพย์สินทางปัญญา, ลิขสิทธิ์/สิทธิบัตร, รางวัลที่ได้รับ, ลิงก์ Classroom Online ส่วนตัว
  - ผลงานวิจัย, ผลงานสร้างสรรค์, ผลงานนวัตกรรม, ผลงานประกวด และทรัพย์สินทางปัญญา แนบรูปภาพประกอบได้หลายรูปต่อหมวด ผ่านหน้า "จัดการรูปภาพผลงาน" (ลิงก์จากรายชื่ออาจารย์ หรือหน้าแก้ไขอาจารย์)
- สไลด์หน้าแรก (hero banner)
- แกลอรี่ภาพกิจกรรม
- สถิติการรับนักศึกษารายปี
- สาขาที่เปิดสอน (การ์ดหน้าแรก)
- ข้อมูลติดต่อ/โลโก้/ชื่อเว็บไซต์ (ตั้งค่าเว็บไซต์)

## หมายเหตุด้านความปลอดภัย

- รหัสผ่านผู้ดูแลระบบถูกเก็บแบบ hash (`password_hash`) ไม่มีการเก็บรหัสผ่านแบบข้อความล้วน
- ทุกฟอร์มในหลังบ้านมีการตรวจสอบ CSRF token
- การอัพโหลดไฟล์ตรวจสอบทั้งนามสกุลไฟล์และ MIME type จริง จำกัดเฉพาะไฟล์รูปภาพ
- อย่าลืมลบ `admin/install.php` หลังใช้งานครั้งแรก

## งานที่ยังไม่ได้ทำ (ต่อยอดได้)

- ยังไม่มีข้อมูล/รูปภาพจริงของสาขาวิชา ต้องเข้าหลังบ้านมากรอกเนื้อหาและอัพโหลดรูปเอง
- ยังไม่ได้เชื่อมโดเมน/SSL จริงบน CloudRambo (ต้องตั้งค่าใน cPanel ตามขั้นตอน hosting ปกติ)
- ยังไม่มีระบบ backup อัตโนมัติ แนะนำตั้ง cron backup ฐานข้อมูลผ่าน cPanel
